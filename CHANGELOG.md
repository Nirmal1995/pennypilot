# Changelog

All notable changes to PennyPilot are recorded here. Versions follow [Semantic Versioning](https://semver.org/).

## [1.0.0] 2026-09-29

### Added
- Transactions CRUD with month, type, category and text filters
- Categories CRUD with colours and expense/income types
- Monthly dashboard: income, spend, net, spending by category, recent activity
- Health, readiness, Prometheus metrics and version endpoints
- Automatic SQL migrations with advisory locking
- Docker images, docker compose stack, Kubernetes manifests (Kustomize), Terraform for GCP, Jenkins pipeline
